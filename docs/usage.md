# xangi-avatar 使い方

## 初期設定

`.env.example`を`.env`へコピーします。`XANGI_URL`は接続するxangi、`XANGI_TOKEN`は接続先がBearer認証を要求するときだけ設定します。faster-whisperは `AVATAR_WHISPER_MODEL=medium` が既定です。Notion会話記録を使う場合だけ、`NOTION_API_KEY`またはmode 0600のtoken fileを指す`NOTION_API_KEY_FILE`を設定します。保存先は`NOTION_CONVERSATION_PARENT_PAGE_ID`を初期値にでき、起動後は設定画面へNotionページURLまたはIDを入力して変更できます。WebUIで保存した値は`.runtime/notion-settings.json`に保持され、次の記録から再起動なしで反映されます。APIキーはブラウザへ返しません。

設定画面の「Notionへの保存を有効にする」で、保存先や既存ログを消さずにブラウザ単位で記録を一時停止・再開できます。キャラクター管理ではプリセットと作成済みカスタムキャラクターのどちらも複製できます。

```bash
npm run setup:voice -- /path/to/xangi-stackchan
npm run setup:workspaces
npm run build
npm start
```

## キャラクターとLocal LLM

xangi本体でAgentを作成し、名前・役割・指示・AI・ワークスペースを設定します。Avatarの設定→キャラクター管理でプリセットを複製し、「使うAgent」を選択して保存します。Agent一覧が空の場合は本体で作成してから「Agent一覧を更新」を押してください。Avatarでは画像・音声を設定します。Local LLMモードと推論設定も本体Agentの設定を使います。未選択・削除済みのAgentでは会話を開始せず、選び直しを案内します。

カスタムキャラクターと現在の選択はDGX側の`.runtime/character-settings.json`へ保存され、同じxangi-avatarへ接続するブラウザ間で共有されます。別checkoutでも同じ保存先を使う場合は、`.env`の`AVATAR_CHARACTER_SETTINGS_FILE`へ共有先の絶対pathを設定します。

ユーザー固有画像は選択したAgentのワークスペースへ配置します。

```text
assets/xangi-avatar/my-character/closed.png
assets/xangi-avatar/my-character/open.png
```

PNG、JPEG、WebP、GIFとHTTPS URLに対応します。相対パスはワークスペース外へ出られません。

## マイクと会話

歯車の「入力マイク」で機器を選びます。初回許可後に実際に使用中の機器名が表示され、選択機器が外れた場合はシステムのデフォルトへ戻ります。

- 「マイクで話す」: 押して録音、もう一度押して送信
- 「連続会話を開始」: 約1秒の無音で自動送信し、読み上げ後に聞き取りを再開
- 「画面共有を開始」: ウィンドウ共有だけを開始し、音声またはテキスト送信時の画面を添付
- 「マイクをミュート」: 画面共有と会話Sessionを維持したまま、マイク入力だけを一時停止

画面共有と音声入力は独立して切り替えられます。共有中は連続会話、1回だけの録音、テキスト送信のどれでも、その送信時点の画面を同じAIターンへ添付します。マイクミュート中は録音せず、連続会話の再開待ち状態と画面共有は維持します。返答待ち・読み上げ中もマイクを休止します。長文は句読点でページ分割し、6.5秒ごとに自動切替します。手動スクロールはありません。

スマートフォンでは、最初に「声を試す」を押して音声再生を有効にしてください。以後のPiper / VOICEVOX応答は、その操作で有効化した同じ音声経路から再生します。ブラウザやOSが音声を再び停止した場合は、もう一度「声を試す」を押します。

Local LLMのbackend・model・動作mode・推論設定は本体Agentの設定を使用し、Avatar側から上書きしません。添付画面は前置きを話さず判断材料に使います。待機中の三点アニメーションはブラウザ表示だけで、AI処理を追加しません。

連続会話の聞き取り開始時は約0.6秒だけ周囲の音量を測り、その環境に合わせて発話判定を調整します。短すぎる音やWhisperが無音・低信頼と判定した結果はAIへ送らず、聞き取りを続けます。認識結果と使用中マイク名は状態表示で確認できます。開始直後の測定中は話し始めず、可能ならゲーム音が直接入らないマイクを選んでください。

## OBS設定

操作用Chromeを開いたまま、OBSへBrowser Sourceを追加します。

```text
# キャラクター（目安 700×1000）
http://localhost:4173/?view=character&background=transparent

# 吹き出し（目安 900×320）
http://localhost:4173/?view=bubble&background=transparent
```

透明背景が使えない場合は `background=green` とOBSのクロマキーを使います。一体表示は `?view=overlay&background=transparent` です。

吹き出しにはアバターの応答だけが表示され、マイクからのプレイヤー発話は表示されません。応答待ちは三点アニメーションになります。OBSに旧表示が残る場合はBrowser Sourceのキャッシュを更新してください。

音声は操作用Chromeだけで再生します。OBSの「macOS音声キャプチャ」でGoogle Chromeを指定し、「声を試す」でメーターを確認します。ゲーム音などでChromeを既に取り込んでいる場合は二重取り込みを避けてください。

## 画面付き会話

Mac ChromeのHTTPS画面で、AIに見せたいウィンドウを共有します。共有開始だけではマイクを開かず、画像も送信しません。音声またはテキストを送信すると、その時点の最大幅1280px JPEGを同じAIターンへ送ります。動画、システム音声、無送信時の画像は送信しません。一時画像は `.runtime/captures/` に0600で保存し、10分後以降の送信時に削除します。ゲーム実況、作業支援、画面を見ながらの相談などに利用できます。

カスタムキャラクターで「画面付き会話を画像と一緒にNotionへ記録」を有効にすると、画面付き会話Sessionごとに親ページの下へ子ページを作り、各turnの時刻、利用者の発話、AI返答、画面画像を非同期追記します。既定は無効で、画像を伴わない通常会話は保存しません。保存エラーが起きても会話は継続します。

Agent作成には同梱のゲーム実況・英会話サンプルワークスペースを利用できます。導入は[XANGI_SETUP.md](../XANGI_SETUP.md)に従います。

### 同梱アバター

各プリセットの口閉じ・口開きPNGは `workspaces/<english|game>/assets/xangi-avatar/<english|game>/` にあります。登録前でも同梱画像を表示できます。画像欄が空なら青の標準画像を使います。別キャラクターの画像はリポジトリへ追加せず、利用者のワークスペースへ配置してください。同梱ロボット画像は作者自身の作品で、コードと同じ [MITライセンス](../LICENSE) で配布します。利用者が追加する画像には、それぞれの権利者が定めた利用条件が適用されます。

操作パネルを表示している間は、キャラクター全体の下にパネルを配置します。縦に収まらない小さな画面ではページをスクロールできます。操作パネル非表示・OBS用表示は従来どおりです。

青い標準画像は `src/assets/avatar-{closed,open}.png` に配置します。assistant専用workspaceは同梱しません。

画像ファイルが見つからない・破損している・取得できない場合も、待機画像と口開き画像それぞれを同梱のデフォルト画像に切り替えます。キャラクター管理の各画像欄の下に読み込み結果を表示します。入力やAgent選択の変更時に確認し、「画像を再確認」で再試行できます。指定したパスは保持されるので、画像を配置した後に再確認できます。画像の失敗で会話や音声は停止しません。

OBS用のキャラ表示はブラウザソースの幅と高さの両方に合わせて画像全体を縮小し、揺れの余白を確保します。

返答言語・長さ・話し方は本体のAgentの指示で管理します。Avatar独自のキャラクター指示は送信しません。

## キャラクターとエージェント

Avatarは選択した本体のAgent IDだけを参照し、Agentやプロジェクトを自動作成・更新しません。本体で変更した名前・役割は一覧更新で表示へ反映され、指示・AIは本体の設定が使われます。

音声設定の言語は音声認識・読み上げ用です。


画面上部に直近の応答で使われたバックエンド・モデルを表示します。本体の実行記録を取得し、AIの自己申告は使いません。設定値だけの場合は「実行未確認」、記録がない場合は「まだ記録がありません」と表示します。新しい会話やキャラクター切替時は表示をリセットします。
